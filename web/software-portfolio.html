NetMon / Linux & network monitoring

See what’s talking
on your network.

Connections, domain context,
and unusual activity to investigate.

Follow the connection. Find the context.

Investigating network activity can mean piecing together connection records, DNS lookups, and device information. NetMon brings those records into a local network dashboard so an operator can explore which devices are connecting where and review activity that needs attention.

The task
Investigate outbound connections, look up remote hosts, and review unusual patterns with their supporting records.
What I built
A Go router agent and a Rails web application with connection search, DNS correlation, activity charts, anomaly review, and grouped incidents.
What you can do
Move from a connection to its remote-host history, inspect associated domains when available, and use allowlists and suppression rules to reduce review noise.
Discuss network monitoringLinux & infrastructure help

Built for use on a local network. Domain context depends on observed DNS data; anomaly scores help an operator decide what to investigate.
